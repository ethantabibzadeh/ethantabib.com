# Ethan Tabibzadeh Adventures

Travel journal website source. Includes destination galleries, nested Eats tabs, visit dates, context, interactive map and contact email.

Work in progress: photo assets are still being transferred. This branch is a source checkpoint, not a complete deployment. The local curated collection contains 287 photos across 26 destination collections. Video integration and further trip curation remain pending.

Run a static HTTP server from the repository root to preview after assets are present.
